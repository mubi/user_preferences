# Changelog

## 1.1.0 2026-07-22
* Add `acts_as_binary` support for multi-value preferences while preserving binary input compatibility
* Fix setting binary preferences with integer values on Ruby 3.2 and later
* Support Rails 8.0 and 8.1 and Ruby 3.3 through 4.0

## 1.0.1 2019-10-17
* Fix compatibility with Rails 6
* Support modern Ruby versions

## 1.0.0 2017-02-13

* Fix compatibility with Rails 5
* Drop compatibility with Rails 3

## 0.0.3 2015-06-15

* Fix Rails 4 deprecation of ActiveRecord::Relation#all
